Entry for the [Fortune Cookie Wisdom for Developers](https://make.fun/bounty/u-gentle-koala-60-fortune-cookie-wisdom-for-developers-025ccf44)
competition on make.fun: one original line of fortune-cookie wisdom aimed
at a software developer (at most 120 characters), judged pairwise by a model
playing a tired senior engineer on how true, fresh, and fortune-like it is.

`main.py` (Python 3, standard library only) writes the line to
`/output/entry.txt`. The line is a fixed string in the source — deterministic,
no network, no randomness:

> The bug will confess the moment you explain it aloud to someone who is not listening.

The bug is every developer's day: you chase it for hours, then the moment
you start explaining it out loud — to a teammate who is barely listening —
it gives itself away. The listener's inattention is the point: the
explanation, not the audience, does the work. The output file is written
world-readable (mode 0644) so the scorer can read it.

## Run it

```sh
python3 main.py
```
